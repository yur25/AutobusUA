# Definition of Done

Цей документ є обов'язковим стандартом самоперевірки завершеності роботи для
всіх п'яти лабораторних. Перед завершенням роботи потрібно перевірити всі
критерії, релевантні для поточної зміни.

## 1. Узгодженість роботи

- [ ] Визначені контекст, мета, scope та критерії приймання.
- [ ] Реалізований результат відповідає узгодженому scope без прихованого
  розширення.
- [ ] Відомі припущення, обмеження та невирішені питання зафіксовані.
- [ ] Архітектурні рішення або узгоджені, або описані в актуальних ADR.

## 2. Реалізація та якість

- [ ] Реалізація відповідає вимогам і межам компонентів/модулів.
- [ ] Оброблені валідні, невалідні та релевантні граничні сценарії.
- [ ] Немає дебаг-коду, тимчасових обходів, невикористаних залежностей або
  необґрунтованих type casts.
- [ ] Помилки обробляються явно, а логування не містить секретів чи зайвих
  персональних даних.
- [ ] Зміни не містять секретів і не порушують встановлені правила безпеки.

## 3. Перевірки

- [ ] Виконані форматування, lint, type-check і збірка, якщо вони налаштовані
  для проєкту.
- [ ] Додані або оновлені сфокусовані автоматизовані тести для нової чи
  зміненої поведінки.
- [ ] Пройдені релевантні unit, integration, end-to-end або smoke-тести.
- [ ] Перевірений негативний результат для критичних перевірок, якщо змінені
  hooks або pipeline.
- [ ] Git hooks автоматично запускаються під час commit/push, якщо вони входять
  до scope роботи.
- [ ] Результати перевірок зафіксовані в описі зміни або журналі роботи.

## 4. Документація та аудит

- [ ] Оновлені пов'язані spec, README, ADR, checklist та приклади, якщо зміна
  впливає на них.
- [ ] Великі артефакти винесені в окремі файли та пов'язані посиланнями.
- [ ] Для foundation- або архітектурної роботи перевірені структура
  репозиторію, відповідність spec і склад залежностей.
- [ ] Для змін пізніших лабораторних перевірені відповідні результати їхнього
  етапу.

## 5. Фінальний стан

- [ ] Зміни переглянуті через `git diff`.
- [ ] `git diff --check` не знаходить помилок форматування.
- [ ] Робоче дерево не містить випадкових або тимчасових файлів.
- [ ] Усі релевантні критерії приймання виконані.
